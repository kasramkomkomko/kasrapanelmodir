# soulsvpn — ربات و پنل مدیریت فروش کانفیگ

همه‌ی تنظیمات (توکن ربات، ادمین، نام برند، کارت، متن همه‌ی پیام‌ها و دکمه‌ها) از داخل پنل وب انجام می‌شود و در دیتابیس ذخیره می‌ماند. نیازی به Variables نیست، به‌جز اتصال دیتابیس.

## دیپلوی روی Railway
1. کد را در GitHub بگذارید و در Railway با Deploy from GitHub repo بسازید.
2. دیتابیس دائمی (برای اینکه با هر دیپلوی تنظیمات پاک نشود، یکی از این دو):
   - **PostgreSQL:** New → Database → PostgreSQL، سپس در Variables سرویس برنامه `DATABASE_URL` را با Add Reference به Postgres وصل کنید.
   - **یا Volume:** یک Volume به سرویس اضافه کنید و Mount Path را `/data` بگذارید (دیتابیس خودکار آنجا ساخته می‌شود).
3. Settings → Networking → Generate Domain.
4. آدرس را باز کنید؛ صفحه‌ی راه‌اندازی اولیه می‌آید:
   - توکن ربات ← شناسه عددی ادمین (قبلاً ربات را استارت کنید) ← کد تایید که ربات برایتان می‌فرستد + رمز پنل.

## بعد از راه‌اندازی
- **پنل‌ها:** آدرس، یوزر و رمز را بدهید؛ نوع پنل خودکار تشخیص داده می‌شود (Marzban، PasarGuard، Marzneshin، 3x-ui و فورک‌هایش مثل Sanaei و Alireza، Hiddify).
- **پلن‌ها:** پلن بسازید.
- **متن و دکمه‌ها:** متن هر پیام، متن هر دکمه و رنگ آن (آبی/سبز/قرمز) را عوض کنید؛ فوراً اعمال می‌شود.
- **پیام‌ها:** پیام همگانی و پیام شخصی.
- **تنظیمات:** نام برند، نام مالک، کارت، پشتیبانی، ادمین‌ها، تغییر توکن ربات (بدون ری‌استارت) و تغییر رمز.

## نکات
- دکمه‌های رنگی با فیلد `style` تلگرام ارسال می‌شوند؛ اگر نسخه‌ی تلگرام کاربر پشتیبانی نکند، دکمه معمولی دیده می‌شود.
- آداپتورهای Marzneshin و Hiddify بر اساس مستندات نوشته شده‌اند و باید یک‌بار روی پنل واقعی تست شوند.
- برای افزودن پنل‌های دیگر (مثل زئوس و اپایدر) مستندات API یا یک پنل تست لازم است.
- اگر ترجیح می‌دهید با Variables راه بیندازید: `BOT_TOKEN`، `ADMIN_IDS` و `WEB_PASS` را بگذارید تا مرحله‌ی راه‌اندازی رد شود.
